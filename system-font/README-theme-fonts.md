# Theme font data

Anunix embeds regular-weight ASCII glyphs from three original font files.
The generated tables use a common 12 × 24 pixel cell and a baseline at row 19.
The bitmap data retains the fonts' SIL Open Font License 1.1.
The original TrueType files remain unchanged in [`sources`](sources/).

## Sources

| 2 | JetBrainsMono Nerd Font Regular, base 2.304 and Nerd Fonts 3.5.1 | [Nerd Fonts commit `b894ea7803af6aade63d60a4381e006098ec9c4d`](https://github.com/ryanoasis/nerd-fonts/tree/b894ea7803af6aade63d60a4381e006098ec9c4d/patched-fonts/JetBrainsMono/Ligatures) | [JetBrains Mono OFL](licenses/JetBrainsMonoNerdFont-OFL.txt), [Nerd Fonts licensing](licenses/NerdFonts-LICENSE.txt) |

[`sources/provenance.json`](sources/provenance.json) records direct download
URLs, SHA-256 hashes, and inspected font metadata. All three sources report
Regular style and OpenType weight 400. The generator checks a constant advance
across all 95 exported ASCII characters.

The JetBrains font reports `JetBrainsMono NF` as its legacy family name and
`JetBrainsMono Nerd Font` as its typographic family name. Its icon glyphs can
have wider advances; Anunix exports only ASCII from U+0020 through U+007E.
The tables do not include the Nerd Font icons or programming ligatures.

## Raster format

[`theme_font_data.h`](../kernel/include/anx/theme_font_data.h) contains:

- `anx_theme_font_alpha[3][95][24 * 12]`: row-major grayscale coverage from 0 to 255.
- `anx_theme_font_bits[3][95][24]`: coverage thresholded at 128, with bit 11 at the left.

The generator renders the original outlines at four times a nominal 20 pixel
size. One uniform transform per face fits the complete ASCII ink bounds into
the cell. The transform preserves glyph proportions and bearings.
Effective sizes are 17.692 pixels for Atkinson, 19.167 for Cascadia, and
18.776 for JetBrains. Atkinson's overhanging underscore limits its fitted size.

The generator checks source hashes, family names, Regular style, monospaced
ASCII advances, empty space, clipping, and glyph survival at threshold 128.
It renders a border outside each destination cell to detect lost coverage.

## Reproduction

The pinned rasterizer is [Pillow 12.3.0](https://pypi.org/project/pillow/12.3.0/)
with [FreeType 2.14.3](https://freetype.org/). The generated file was produced
with Python 3.14.7. The generator rejects different Pillow or FreeType versions
because rasterizer changes can change coverage values.

From the repository root, the generation commands are:

```sh
python3 -m venv /tmp/anunix-theme-fonts
/tmp/anunix-theme-fonts/bin/pip install -r system-font/requirements-theme-fonts.txt
/tmp/anunix-theme-fonts/bin/python tools/gen_theme_fonts.py \
  --preview /tmp/anunix-theme-font-specimens.png
/tmp/anunix-theme-fonts/bin/python tools/gen_theme_fonts.py --check
```

`--check` compares generated bytes with the checked-in header and does not
write the header. `--output <path>` selects another output file. Ordinary
kernel builds consume the checked-in table and need no Python font packages.

The contact sheet shows all ASCII glyphs, grayscale and binary variants, and
confusable-character samples. Each atlas appears at twice its native size;
sample text appears at native size. The inspected sheet showed complete
glyphs without clipped marks, including underscores and descenders.

# Day 003: Model request budgets

The June 28 briefing treats time, tokens, memory, and permissions as resources under deterministic control.
Anunix already defines cell constraints and engine leases.
The baseline model server accepts expired requests and output limits above the model's context capacity.
The cell runtime omits its token and time limits from model requests and ignores submission errors.

## Implementation

Model servers reject expired deadlines before serving a request.
They reject an output limit above a known model context capacity.
A zero output limit adopts the model capacity; zero capacity remains unknown.
Rejected requests do not increment the count of served requests.

The cell runtime passes its cognitive token limit to the model server.
The runtime derives an absolute deadline from the execution start time and the cell's latency limit.
An unrepresentable deadline saturates at the largest timestamp instead of wrapping.
Submission errors propagate through the cell's existing failure and trace path.

The native regression checks rejected and accepted requests through the server API.
The regression also runs cells through routing and model dispatch.
An excessive token limit fails the cell without serving the request.
An allowed limit completes the cell.

The existing lease path reserves 4096 bytes for the test model server.
An over-capacity request fails without consuming the remaining reservation capacity.
Stopping the server returns the reservation.
The regression removes its own test server, cells, and engine.

## Limits

The model-server backend remains an inference stub.
These tests establish admission behavior and reservation accounting, not generated-token limits during real inference.
The deadline check rejects expired work at admission; it does not preempt an active backend.
The request descriptor lacks input-token counts, so the check cannot establish total prompt-plus-output capacity.
Engine leases retain their existing configured capacity; the test does not establish physical memory allocation.
Tool spending, currency budgets, and the separate Anxml dispatch path remain outside this change.

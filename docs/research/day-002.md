# Day 002: Validated workflow artifacts

The June 27 briefing recommends reusable, tested workflows for repeated agent tasks.
Anunix already provides workflow templates, a registry, binary bundles, and a DAG executor.
The baseline importer checks header fields and total size but accepts malformed template contents.

## Implementation

The template validator checks counts before array access or serialization.
The validator requires terminated strings, supported node kinds, consecutive node identifiers, and bounded ports.
Each edge must connect an existing output port to an existing input port.
Declared types must agree unless one port accepts any type.
The validator rejects duplicate producers for an input and rejects graph cycles.

Both serialization and library registration use the validator.
Bundle registration requires an exact byte count and copies the header before reading its fields.
That copy permits an unaligned input buffer.
Failed registrations release the temporary template allocation.
Successful registrations retain their own copy for the library lifetime.

Completed workflows persist their execution traces independently of JEPA observation availability.
The previous trace path required JEPA observations before it created the trace object.

The regression checks thirteen malformed imported templates and three oversized producer counts.
Other checks cover short bundles, trailing bytes, duplicate imports, and an unaligned buffer.
The regression also serializes every existing registered template.
A valid imported workflow runs through two nodes and records both results in its trace object.
The regression clears the caller's bundle buffer before execution to check ownership of the imported copy.

## Limits

Structural validation establishes that the executor can interpret the artifact's graph.
The change does not authenticate a publisher or certify workflow behavior.
The existing version-one bundle format still embeds native C structures.
Portable serialization, signatures, capability manifests, promotion, and rollback remain separate work.
Trace persistence remains best effort when object allocation fails.
The valid test workflow uses deterministic control nodes; the test makes no model-quality claim.

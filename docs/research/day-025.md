# Day 025: Expose a bounded, revocable tool namespace

The July 20 briefing separates a complete tool catalog from the small authorized set exposed to an agent.
The comparison baseline, `5111209`, has capability records and a transport registry but no per-scope catalog or versioned invocation handle.
The baseline cannot withdraw one tool grant while retaining another through those transport APIs.

## Scope

The source is [Day 025 in the daily review](daily-review.md#day-025--2026-07-20).
The source message identifier is `b3e419a3-edae-45ea-9b87-b3975f94202c`.
This step adds bounded discovery and revocable handles over the existing native external-call registry.
The implementation does not add a semantic search service or another transport protocol.

## Implementation

The [tool namespace API](../../kernel/include/anx/tool_namespace.h) supports 64 active tool descriptors and 256 namespaces per kernel lifetime.
Each namespace contains at most eight tool grants.
A descriptor fixes the endpoint, method, schema version, and declared authority needed for invocation.
The catalog rejects malformed descriptors and duplicate active names.

Trusted control code creates a namespace on an unbound root cell before execution.
Derived children inherit the namespace; ancestry checks reject a changed or removed child binding.
An empty namespace exposes no tools.
Cells without a namespace retain legacy transport behavior.

Each grant separates discovery from invocation.
Discovery filters the current grants and the cell's authority before copying entries to the caller.
An optional identity commitment also constrains discovery and invocation.
The caller chooses a capacity from one through eight entries; discovery returns no more than that capacity.
The result order follows the namespace's grant order.

The [registry](../../kernel/core/cap/tool_namespace.c) returns each descriptor with its namespace identifier, namespace generation, tool identifier, and tool generation.
Replacing grants advances the namespace generation and invalidates earlier handles.
Updating a descriptor advances the tool generation and invalidates handles for that descriptor.
Stale controller updates return `ANX_EBUSY` without changing grants or descriptors.

The external-call descriptor now carries the tool handle.
Both runtime admission and the [transport registry](../../kernel/core/exec/external.c) check the handle before dispatch from a bound cell.
The invocation must match the registered endpoint and method exactly.
Discovery alone does not authorize invocation.
Active cells cannot replace tool grants, mutate the catalog, or replace transport handlers.

| Condition | Result |
| --- | --- |
| Invalid capacity, descriptor, or grant list | `ANX_EINVAL` |
| Stale namespace or tool generation | `ANX_EBUSY` |
| Missing invocation grant or insufficient authority | `ANX_EPERM` |
| Missing handle, foreign namespace, or changed endpoint or method | `ANX_EPERM` |
| Authorized descriptor removed from the catalog | `ANX_ENOENT` |
| Valid current handle and matching operation | Existing transport handler executes |

The [native regression](../../kernel/core/tools/research_day025.c) limits discovery to authorized entries and checks a one-entry result capacity.
The fixture rejects a hidden tool, a discovery-only tool, and a tool beyond the cell's network authority.
The test also rejects altered endpoints, altered methods, missing handles, foreign namespace identifiers, and stale descriptor generations.
Revocation blocks earlier handles, removes invocation permission, and later removes the tool from discovery.
A refreshed authorized handle reaches the native handler and returns its expected response.

## Limits

The namespace bounds descriptors by entry count, not model tokens or schema bytes.
The change adds no dependency expansion, lexical ranking, vector retrieval, connection pool, or backend session router.
Schema versions identify descriptor revisions; the API does not validate request bodies against a schema.

Namespaces have no expiration timer, disk restore, or reclamation API.
Tool removal frees a catalog slot, but namespace records remain until reboot.
The generation checks do not authenticate an operator; mutation APIs trust control code outside an active cell.
Trusted kernel code retains raw transport access.

The synchronous tests do not establish atomic revocation during an already-admitted handler or concurrent backend replacement.
The fixture covers four native descriptors, not a production catalog with thousands of tools.
The briefing's retrieval, token-use, and latency thresholds remain unmeasured.

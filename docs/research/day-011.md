# Day 011: Bounded memory admission

The July 6 briefing treats memory as a governed resource alongside agent execution and tool admission.
Anunix's memory plane tracks logical tiers, freshness, and validation.
The comparison baseline, `a8fe0cc`, has no per-cell byte admission limit.
It accepts a new memory entry without resolving the source object or charging its payload size.

## Scope

The source is [Day 011 in the daily review](daily-review.md#day-011--2026-07-06).
The source message identifier is `e231e283-bef2-43f6-8daa-b98afc7755e8`.
This step limits newly admitted object payload bytes for a running cell.

## Implementation

The new `max_memory_admission_bytes` constraint enables a per-cell limit; zero retains unbounded behavior.
Memory admission resolves the source through the ordinary read access API.
Bounded admission requires a sealed source, checks remaining capacity without overflow, and charges its payload bytes.
A child cannot remove or increase an inherited bound.

Each bounded entry holds a reference to its accounting owner.
Hard forgetting returns the charged bytes and releases that reference.
Tombstoning, archiving, and tier changes retain the admission charge.
An owner cannot be destroyed while it still owns those entries.
This guard also applies after its caller releases the original cell reference.

The [native regression](../../kernel/core/tools/research_day011.c) uses a sixteen-byte budget.
After admitting eight bytes, it rejects a nine-byte candidate and reads the original content unchanged.
Another eight-byte object fits exactly; forgetting it returns the charge.
An unsealed candidate is rejected, and the remaining entry prevents owner destruction until it is forgotten.
The Day 006 regression also checks that a child cannot remove the new inherited bound.

## Limits

This is accounting for admitted payloads, not physical RAM, allocator overhead, peak RSS, or accelerator memory.
The budget applies to one cell and does not aggregate a subtree's consumption.
The memory plane retains one global admission record per object identifier.

Existing admissions and unbounded kernel activity retain their previous ownership behavior.
The change does not provide automatic eviction or automatically forget a completed cell's memory.
Callers must explicitly forget bounded entries before reaping their owner.
Memory plane registry operations retain their existing synchronous concurrency assumptions.
